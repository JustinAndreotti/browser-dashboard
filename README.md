# browser-dashboard
Work in progress browser/server dashboard

## Clone the repository
```
git clone https://github.com/JustinAndreotti/browser-dashboard.git
cd browser-dashboard
```

## Install dependencies
```
npm install
```

## Rename .env.example to just .env
